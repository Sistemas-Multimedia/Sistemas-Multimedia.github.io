1 The Visual Coding Framework (VCF) project

VCF [2] is a Python [1] application1 that implements a collection of algorithms used in image and video compression. VCF is hosted at GitHub and developed with the help of the students of Sistemas Multimedia.

2 Recommended working environments

2.1 Using your operating system

Running VCF natively is the preferred solution. VCF modules should run on any machine with a Python interpreter installed. Said that, it is recommended to use Linux or a UNIX-based OS (such as Apple OS). However, with some configuration effort (for example, after installing Python), VCF should run also in Windows. Notice also that, in Windows, the Windows Subsystem for Linux (WSL) is also available.

2.2 Using a virtual machine

VCF works also in any Linux installed in a virtual machine (VM) , such as Virtual Box, VMware, and Parallels. The only drawback of this option is that you will require some extra memory and CPU power, compared to the previous solutions.

2.3 Using a container

Compared with using a VM, a lower computational-demanding alternative is to run Linux in a container, such as the provided by Docker (example for Ubuntu) or LXD. Notice, however, that you will need to run graphical applications (such as ImageMagick and Firefox) in your container.

2.4 Using notebooks

VCF modules can be created and invoked from Jupyter notebooks. Notice, however, that in the case of the cloud envinronments, such as Google Colaboratory, Kaggle, and Binder, you will have to reinstall the VCF envinronment from scratch every time the virtual envinronment is started.

3 About the programming environment

VCF is fully written in Python [4]. You will also need to interact with a commands line terminal. In any case, it is quite recommended to use virtual environments. For this, use (for example): 

python3 -m venv VCF
source VCF/bin/activate # In Linux and OSX
# VCF\Scripts\activate.bat # In Windows using cmd.exe
# VCF\\Scripts\Activate.ps1 # In Windows using PowerShell

An Anaconda environment is also a good solution.

4 About the software versioning system

VCF is hosted by GitHub throughout Git [3]. Therefore, you will need a GitHub account and install Git in your computer.
